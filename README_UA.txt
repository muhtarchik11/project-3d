PROJECT 3D — 3D ONLINE ALPHA

ЩО ПРАЦЮЄ:
- Онлайн-кімната до 5 підключень через WebSocket, шестисимвольний код.
- Відображення інших гравців як блакитних 3D-персонажів на карті.
- Синхронізація позиції та напрямку, плавне відображення руху.
- Офлайн-режим із ботами, гараж і редактор кнопок із попереднього прототипу.

ЗАПУСК СЕРВЕРА (на комп'ютері або хостингу з Node.js):
1. npm install
2. npm start
3. Відкрити http://localhost:3000 або HTTPS-адресу хостингу на телефоні.
4. На двох пристроях ввести однаковий код і натиснути «Приєднатись», потім «ГРАТИ».

ВАЖЛИВО: сервер НЕ розміщений в інтернеті; потрібен власний хостинг. Для телефонів поза локальною мережею потрібен HTTPS/WSS.
Це експериментальний прототип, без авторизації, античита, синхронізації стрільби, авто, інвентарю, матчмейкінгу чи голосового чату.
Позиції передаються з клієнтів, тому сервер не захищений від шахрайства.
Three.js завантажується з CDN; потрібен інтернет.
