PROJECT 3D — ФАЙЛИ ДЛЯ ПУБЛІКАЦІЇ

Це експериментальна 3D вебгра з WebSocket-кімнатами до 5 гравців.
Це НЕ готова мобільна програма, НЕ завершена мережева гра.

ЩО В ПАКЕТІ
index.html — гра
server.js — Node.js сервер для гри і WebSocket
package.json — залежність ws і команда запуску
render.yaml — конфігурація вебсервісу для Render

ЯК ОПУБЛІКУВАТИ (потрібен обліковий запис GitHub і Render)
1. Розпакуй архів і завантаж УСІ файли з папки Project3D_Web_Deploy в корінь нового репозиторію GitHub.
2. На Render обери New > Blueprint і підключи цей репозиторій.
3. Перевір налаштування та підтвердь створення вебсервісу. Безкоштовний тариф і його доступність можуть змінюватися.
4. Після успішного розгортання Render покаже HTTPS-адресу. Саме її відкривай у Safari/Chrome.
5. На двох телефонах відкрий однакову адресу, введи ОДНАКОВИЙ шестизначний код кімнати і підключись.

ВАЖЛИВО
• Це одна серверна інстанція: кімнати зберігаються лише в пам'яті і зникають при перезапуску.
• Кімнати не захищені паролем: код не слід вважати приватним доступом.
• Для 3D потрібен доступ до CDN із Three.js; без інтернету сцена може не завантажитися.
• Немає реєстрації, справжнього матчмейкінгу, голосового чату чи серверної перевірки стрільби.
• Сервер ще не розгорнутий; цей ZIP сам по собі не є посиланням на сайт.
• Для онлайну не підійде суто статичний хостинг, потрібен Node.js з WebSocket.
• На безкоштовному хостингу можливе засинання сервісу та затримка при першому вході.
